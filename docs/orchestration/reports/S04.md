## Delivered contract and observations

The public facade exports `resolvePropertyPath`, `PropertyPathError`, `PropertyPathErrorCode` and
`ResolvedPropertyPath`, alongside the existing reflection/path types. Resolution returns a canonical string,
ordered reflected segments, final property, root context, target, optional ancestor prefixes and accumulated
`one`/`many`/`unknown` multiplicity. The descriptor/array containers are frozen and input arrays are copied.

Every segment is checked through reflected property-type metadata, including the previously skipped two-level
context. Inherited/optional/nullable singular targets, arrays, generic arrays and record elements resolve correctly.
Explicit inverse/N-N relation facts remain attached to their logical segments. Finite cycles and different routes
to the same class retain their full paths, without imposing automatic-search decisions.
Empty/malformed/unknown paths, terminal traversal, ambiguous unions and unknown intermediate targets reject with
explicit error codes and failing prefixes. No record getter, `ReflectProperty.value` or domain constructor executes
during metadata resolution or `ReflectPropertyPath` construction.

`ReflectPropertyPath` retains the inherited final-property API and accepts class/object/reflection roots. Explicit
`object`, `class.object` or `value` access resolves and remembers the final singular value owner on first access;
missing parents yield `undefined`. Plural ancestry has no singular owner and never chooses an element.
Declared metadata supplies the class independently of a record subtype. Custom root type/default metadata remains
substitutable. Type helpers traverse collection elements and preserve final names/values; repeated context types
widen the remaining suffix to prevent circular eager expansion, while runtime resolution validates every segment.
