## Diagnostic history and limitations

Early restricted process launches in `/tmp/property-select/L5` did not expose listeners to the host browser. Their
namespace PID records could not be safely verified from the escalated host (`EACCES` on `/proc/14/exe` and
`/proc/17/exe`). Those ambiguous records were retained; no process was signalled using them. The separate approved
service directory solved the test setup without reducing browser security. A custom-directory `status` initially
looked for a nonexistent local SQL socket; the canonical SQL directory plus explicit app port is the successful check.

Early node test invocations under restricted subprocess handling did not run the intended file set. Combining suites
with isolation disabled also exposed shared global fixture interference. The final runner uses absolute file paths
and Node's normal process isolation, and all suites pass. This was not accepted as a product test failure or success.
The export inventory initially assumed a nonexistent home entry `cjs/home.js`; the actual manifest exports
`cjs/output.js`, which the corrected inventory checks.

The object-layout diagnostic remains versioned. Superseded runs are archived under `/tmp/property-select/L5/`;
[historical-evidence.json](../evidence/L5/historical-evidence.json) records the stable archive path and SHA-256. During development,
external arrival direction, visible freeze-edge scrolling, provisional-marker precedence and row-snapshot rollback
were corrected in their owners. The 768-pixel object case in `object-geometry/browser.json` was a driver error: its
sample x=73.375 was chosen before object data widened cells, leaving it left of the frozen boundary x=79.375.
The correct result was cancellation. That case now remeasures geometry after its data-dependent layout change.
The separate held-values case still proves that valid drop does not depend on values completing.

Final replay after these corrections passes all L5 checks. Earlier intermediate results are historical, not current
verdicts. No physical touch, hybrid-device arbitration, independent V5 or final phase acceptance is claimed.
