## Implementation and contracts

96 CSS pixel start zone from the selector's left edge. There is no timer. The first movement crossing the threshold
locks native or transport intent until release. Mouse/pen retain their existing distance convention.

pending or active transport. The horizontal breadcrumb retains native touch scrolling; its objects remain transportable
through relation rows and result segments, while breadcrumb mouse/pen dragging remains available.

losing the surviving controller's capture cancels. A new primary contact clears obsolete click suppression,

including changes during transport; default suspension is unchanged. Tokens retain owner/generation checks, nesting,
scroll state and removal invalidation. Restoring a token never focuses search. Opening uses a 120 ms fade, disabled
under reduced motion.

and column saving settle, or after rollback/rejection. The active operation remains reserved while saving.
The table's public external operation owns every insertion, frozen boundary, value preview and edge scroll;
no table source change was required.
