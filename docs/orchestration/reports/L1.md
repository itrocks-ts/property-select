## Implementation and behavioural evidence

`src/property-select.ts` exports the controller, normalisation and narrow structural ports. The build delivers a root
CJS facade, public browser `property-select.js`, declarations and relative ESM dependencies. API imports have no DOM
activation side effect or host/framework/reflection/SQL/Node dependency. Generated files are ignored.

`Navigation` owns branch/current and per-instance context caching. Every navigated edge must be a relation. Root is
navigable only. Returning through a remembered prefix retains its descendants; divergence replaces only its suffix.
Provider business order uses full path as deterministic final tie-breaker; empty labels fall back to names.
Caches belong to the fixed authorised provider catalogue snapshot of the instance. Recreate the controller when that
catalogue changes; no user metadata cache is global. It loads one context at a time and never loads records.

`Intentions` owns unique attempt identities, immutable root/path, consumer callbacks and terminal lifecycle.
An observer-only host receives intentions without an implicit addition. Only a valid `added` acknowledgement updates
recent destinations. Unknown, premature, mismatched, duplicate and disposed acknowledgements are ignored/reported.
An ending transport cannot send a second terminal callback. Consumer failures report recoverable errors and preserve
navigation. Rapid attempts retain separate ids; actual host duplicate reservations remain the consumer's responsibility.

`PropertySelect` composes the two owners and supplies translation/default lists, subscriptions, configuration updates
and detached JSON-serialisable state. State includes branch/current/query/recent/scroll only. Instance mode is explicit
in examples and is the deterministic default; session mode rejects until the L4 adapter delivery. The exported neutral
`StateStore` contract is not presented as implemented persistence. Search and suggestion fusion remain L3/L4.

Metadata uses abort plus generation checks. Intentions use per-attempt ownership plus disposed-instance checks.
Disposal aborts pending selection/metadata work, cancels active transport once, removes listeners and prevents late
results reviving the controller. The transport methods are contract calls; gesture recognition/capture are L5/L6 work.

The reusable static fixture graph covers invoice/customer/address/city/country/line/tag, multiple routes to the same
type, inverse and N-N edges, unknown cardinality and cyclic customer parents. Its recording consumer owns only a plain
list of selected paths and callback observations. No table, framework adapter, business-value read or SQL is involved.
