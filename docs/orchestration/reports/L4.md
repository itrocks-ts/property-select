## Delivered responsibilities

- Selector: per-instance revision queue, bounded versioned state validation, latest-local-snapshot conflict recovery,
  visible persistence errors/retry, remembered branch/current/query/recents/scroll restoration and metadata refresh.
  Suggestions merge confirmed recent contexts, maximal used contexts per branch and advice, deduplicated by full path with metadata labels and host translation.
  Exact shortcuts replace the branch and clear search. Only confirmed `added` outcomes feed recents.
- List: request-scoped `SessionStateStore`, authorised `/property-select/state/json` GET/PUT/DELETE actions,
  tombstones and canonical router identities retaining identifying ids while omitting query/format.
  `session.propertySelect` remains distinct from `session.list`. `HttpStateStore` uses same-origin credentials,
  CAS revisions and an opaque session-generation header; old mounted selectors receive 410 after session replacement.
- Framework: public composition binds session transactions and root advice. The selector knows no HTTP routes,
  framework, list, table, reflection, SQL or user identity.
- Fastify: public request-bound `sessionTransaction`, generation-aware reload, normal response autosave through the
  configured store. Public script dependency discovery survives cached parent scripts after a server restart.
- File store: authoritative reads under a session-wide lock, request-delta merge, atomic file replacement, detached
  snapshots and per-instance weak leases. All writes/autosaves/revoke share coordination; expired, missing or revoked
  generations cannot be resurrected. Lock entries release after success or failure. No global session-data cache.

SOLID review: state validation/queue, navigation, suggestions and rendering retain separate responsibilities.
The selector's small `StateStore` and metadata ports support memory/HTTP substitution; list owns route/session policy;
HTTP/storage own session lifecycle, and framework alone chooses their composition. No reverse dependency, private
owner import, SQL in list, hydration in selector, table geometry copy or new infrastructure package was added.
Snapshots contain only the six declared state fields; no rows, previews, transports or provisional drag state persist.
